    Why this tool is safe to run

    • Pure function — numbers in, numbers out
    • Same input gives the same answer, every time
    • No outbound network: fetch, WebSocket, raw sockets
    • No dynamic execution: eval, Function, dynamic import
    • Generated code is scanned against that policy before it is deployed

    The gate is a scan of the generated source paired with a per-request isolate boundary — not a full sandbox, and we do not claim one. On the hosted platform every call's input and result are stored for billing and debugging, so production tools should not be given sensitive data.
