# ActionForge UI

Static marketing pages and interactive demo for ActionForge. Preview with `python3 -m http.server 8000`. `demo.html` is a demonstration interface, not an authenticated customer dashboard. Never enter real API keys or private customer data into the demo. Review script network calls before connecting a production API.

The shared display asset is the small `mark.png`; `logo.jpeg` is not referenced by the HTML pages. WebP conversion enlarged the mark, so the original remains. Hosting settings and backend deployment are outside this PR.
